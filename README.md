# ModeLibrary 🥭

**Управляй поведением ИИ через текстовые команды**

- 20+ режимов (манго, пират, грусть, энерджайзер, баг, эмоции...)
- 7 расширенных режимов (хаос, дуал, микс...)
- Крестики-нолики (3х3–8х8, 4 уровня сложности)
- Поиск музыки по тексту
- Автоматическое переключение языка
- Ролевые игры
- Защита авторства
- Чистый код по запросу
- Пасхалка на мем (открываются секретные команды)
- Игры (/quiz и т.д)
- Создание своих стилей речи (/createmode)
- Положил файл в чат дипсика и все работает! (или вставил промпт)
